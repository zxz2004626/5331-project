# 实验产物

| 目录 | 用途 | 是否随仓库保存 |
| --- | --- | --- |
| `evaluation/<scenario>/runs/` | 每个评估单元的指标和来源记录 | 是 |
| `evaluation/<scenario>/*.csv` | 逐次指标与五种子汇总 | 是 |
| `official/` | 官方复现、预测和时间协议对照 | 是 |
| `no_pair/` | prior-pair 特征移除对照 | 是 |
| `report/` | 报告表格、图形和摘要 | 是 |
| `validation/` | 历史独立核验及其限制 | 是 |
| `logs/` | 原运行控制台日志 | 本地保留；新日志忽略 |
| `cache/` | 全量特征、注入审计、诊断 | 否，按配置重建 |
| `evaluation/*/models/`、`predictions/` | 扩展模型与预测数组 | 否，按配置重建 |

历史记录可能包含原执行机器的绝对路径和旧源码哈希；这些是证据，不是运行配置。迁移时程序只依据当前项目路径。重构后不要修改旧数值或伪造匹配的新哈希。
